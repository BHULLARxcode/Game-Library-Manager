# Game Library Manager

A Python-based Game Library Manager that allows users to manage their favourite games using JSON file storage.

## Features

- Add new games
- Remove games
- Search for games
- Display all games
- Count total games
- Rename games
- Clear the games list
- Save and load games using JSON

## Technologies Used

- Python
- JSON
- File Handling
- Exception Handling

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run `main.py`.
